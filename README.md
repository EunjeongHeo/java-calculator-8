## 기능 구현 목록

- [x] 기본 입출력 기능을 구현한다.
    - [x] 사용자에게 `"덧셈할 문자열을 입력해 주세요."`라는 안내 문구를 출력한다.
    - [x] 콘솔로부터 문자열 입력을 받는다.
    - [x] 임의의 값 X를 `"결과 : X"` 형식으로 출력한다.


- [x] 입력값을 ‘쉼표(,) 기본 구분자’, ‘콜론(:) 기본 구분자’, ‘양수’로 받아들이는 기능을 구현한다.
    - [x] 기본 구분자를 기준으로 문자열을 분리한다.
    - [x] 분리된 각 항목이 양의 정수인지 검증한다.


- [x] 문자열 앞부분의 `"//"`와 `"\n"` 사이에 위치한 문자가 있다면 '커스텀 구분자'로 작동하도록 구현한다.
    - [x] 기본 구분자와 커스텀구분자를 기준으로 문자열을 분리한다. (함께 사용가능하도록)
    - [x] 분리된 각 항목이 양의 정수인지 검증한다.


- [ ] 잘못된 입력값인 경우, `IllegalArgumentException`을 발생시키고, 애플리케이션을 종료한다.
    - [ ] 음수는 잘못된 입력값으로 처리한다.
    - [ ] 소수점이 포함된 양수는 잘못된 입력값으로 처리한다.
    - [ ] 공백만 있는 문자열은 잘못된 입력값으로 처리한다.
    - [x] 잘못된 커스텀 구분자 형식은 잘못된 입력값으로 처리한다.
    - [ ] 그 외 허용되지 않는 값이 있다면 잘못된 입력값으로 처리한다.


- [ ] 정상적으로 들어온 입력값을 기반으로 각 숫자의 합을 계산하고, 계산한 값을 `"결과 : X"` 형식으로 출력한다.


- [ ] 빈 문자열(`""`) 입력 시에는 0을 반환한다.

## 테스트 코드 목록

- [ ] 성공 케이스에 대한 테스트 코드를 추가한다.
    - [ ] `""` → 0 (빈 문자열 입력 시)
    - [ ] `"1,2"` → 3 (쉼표 구분자만 사용 시)
    - [ ] `"1,2,3"` → 6 (쉼표 구분자만 사용 시)
    - [ ] `"1:2:3"` → 6 (콜론 구분자만 사용 시)
    - [ ] `"1,2:3"` → 6 (기본 구분자 함께 사용 시)
    - [ ] `"//.\n1.2.3"` → 6 (커스텀 구분자만 사용 시)
    - [ ] `"//.\n1.2,3:4"` → 10 (기본 구분자와 커스텀 구분자 함께 사용 시)


- [ ] 실패 케이스에 대한 테스트 코드를 추가한다.
    - [ ] `"-1,-2:3"` → `IllegalArgumentException` 발생 (음수 포함 시)
    - [ ] `"1.2,2:3"` → `IllegalArgumentException` 발생 (소수점 포함 시)
    - [ ] `" "` → `IllegalArgumentException` 발생 (공백만 있을 시)
    - [ ] `"//안녕하세요\n1;2;3"` → `IllegalArgumentException` 발생 (잘못된 커스텀 구분자 형식일 시)
    - [ ] `"1+2"` → `IllegalArgumentException` 발생 (그 외 허용되지 않는 값이 있을 시)
